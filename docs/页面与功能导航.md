# 页面与功能导航

本平台共44个HTML页面，由登录入口、26个学生小组端页面和17个教师总控端页面组成。所有业务页面使用统一状态模型，课堂数据经服务端鉴权后保存到 SQLite。

## 学生小组端（26页）

### 课堂入口与横向工作台
- `student/dashboard.html`：课堂首页、五阶段进度、阶段产出、提示额度、角色与教师广播。
- `student/workspace.html`：共同问题空间，集中呈现当前问题、变量、模型、证据、待核验点和下一步。
- `student/help.html`：已有进展与具体卡点、L1-L3最小充分提示、网络降级静态支架、转教师。
- `student/group.html`：角色轮换、个人先想、组内协作规则。
- `student/history.html`：阶段提交、版本与提示使用回看。
- `student/governance.html`：数据最小化、AI边界、教师责任与学生权利说明。

### 阶段1 项目准备与支架预设
- `student/stage1.html`：项目目标、成果对象、数学用途、阶段任务。
- `student/stage1-materials.html`：项目资料与材料清单。
- `student/stage1-roles.html`：角色确认与轮换规则。

### 阶段2 情境导入与任务理解
- `student/stage2.html`：阶段总览与任务进入。
- `student/stage2-understanding.html`：任务复述、已知/未知/变化量/约束表。
- `student/stage2-question-tree.html`：驱动问题—子问题树。

### 阶段3 方案设计与数学建模
- `student/stage3.html`：阶段总览、变量与模型产出。
- `student/stage3-model.html`：变量定义、数量关系、模型V1/V2、修改理由。
- `student/stage3-graph.html`：二次函数图像与工具性验证。
- `student/stage3-compare.html`：并列方案比较、证据和限制。
- `student/stage3-check.html`：范围、单位、约束和合理性核验。

### 阶段4 协作探究与过程调节
- `student/stage4.html`：阶段总览、证据与模型修订。
- `student/stage4-evidence.html`：过程证据包。
- `student/stage4-discussion.html`：证据型异议、观点回应与复杂冲突转教师。
- `student/stage4-versions.html`：模型版本比较与修订理由。
- `student/stage4-tools.html`：重复计算、单位换算与工具性支持。

### 阶段5 成果表达与反思评价
- `student/stage5.html`：阶段总览。
- `student/stage5-product.html`：问题—模型—证据—结论—局限成果结构。
- `student/stage5-rehearsal.html`：展示预演与自检。
- `student/stage5-reflection.html`：提示使用、角色责任、模型修订和方法迁移反思。

## 教师总控端（17页）
- `teacher/dashboard.html`：课堂总览，当前阶段、需教师小组、共性卡点、AI调用与多组态势。
- `teacher/project.html`：班级、项目、五阶段目标、必交产出与功能规则。
- `teacher/template.html`：微型/标准/深度课时模板。
- `teacher/knowledge.html`：教师审核项目资料、知识约束与RAG接口占位。
- `teacher/scaffolds.html`：L1-L3提示模板、最高层级、静态降级支架。
- `teacher/stages.html`：阶段开放/暂停/推进、AI开放/暂停和时间控制。
- `teacher/groups.html`：已配置小组的课堂态势。
- `teacher/group-detail.html`：小组原始产出、求助、提示链、角色、版本与教师处理。
- `teacher/queue.html`：需要教师事项队列。
- `teacher/common.html`：多组相似卡点聚合。
- `teacher/broadcast.html`：全班/选组广播。
- `teacher/evaluation.html`：成果证据辅助查看与教师最终评价。
- `teacher/report.html`：课后过程摘要。
- `teacher/export.html`：去标识化CSV/JSON导出。
- `teacher/governance.html`：数据库、会话、模型调用和数据量的真实运行状态，以及固定产品边界。
- `teacher/audit.html`：教师关键操作、模型调用和错误审计。
- `teacher/access.html`：教师账号、班级码、小组码与管理员恢复码重置。

原静态“系统版本”“研究接口”和4个专家评审页面不具备独立业务闭环，已从生产运行端删除。项目配置变更由操作审计记录，课堂数据由导出页提供；需求追溯和专家评审保留为离线项目文档，不伪装成在线功能。
