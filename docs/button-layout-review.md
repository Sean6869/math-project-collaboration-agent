# 按钮布局修复与验收

日期：2026-10-25。

## 根因与修改

- 自由AI面板设置了最大高度，聊天内容又有最小高度；增加图片操作后，底部操作区被压缩并被面板裁切。取消面板高度上限，仅限制聊天记录区滚动，输入框、附件和操作区按内容正常增长。
- 拍照、选图、识别、生图和发送统一到输入框下方的右侧操作区，电脑端等宽等高；手机端采用两列网格，发送位于右下角。图片预览放在独立行，避免挤压按钮。
- 通用按钮允许内容撑开和必要换行；文件操作按钮不再固定窄宽度；保留HTML的隐藏状态，避免通用显示样式使隐藏按钮重新出现。
- 手机顶部改为两行布局，项目切换占完整一行，解决项目按钮挤压与320px屏幕横向溢出。
- 数学工具区及方案表征页的工具选项改为可换行网格，修复手机上后几个工具按钮被卡片裁切的问题。

## 验证

- 浏览器覆盖44个师生页面，屏幕尺寸为1680×945、1024×768、768×1024、390×844、320×740。
- 加测师生登录、项目选择、证据上传弹窗、AI三图预览及输入框展开，共250个页面/状态与尺寸组合，未发现按钮文字溢出、隐藏区域裁切、整页横向溢出或脚本错误。
- 拍照、文件选择、识别确认、AI失败重试、方案版本、个人记录、评价发布、离线恢复及冲突处理浏览器验收通过。
- 76项自动回归通过。手机与平板使用浏览器视口模拟，未宣称完成物理设备或系统软键盘验收。
