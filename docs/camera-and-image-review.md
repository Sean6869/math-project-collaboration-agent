# 拍照与图片识别验收

日期：2026-10-24。

- 修复服务器全局 `camera=()` 导致的相机不可用，仅在个人记录、方案、证据、AI及教师项目配置页面开放同源相机；不采集音频。
- 统一取景、拍摄、重拍、确认和关闭流程，优先请求后置摄像头；不支持网页相机时使用 `capture="environment"` 的系统相机入口。
- 图片文件选择与拍照并存；教师材料及证据保留PDF等文件选择。关闭、离开页面、取消待处理请求后均释放相机。
- 学生聊天新增最多3张图片附件及独立识别入口，用户核对后才填入输入框；图片不会自动改写模型或结论。
- 识别及图片对话复用现有方舟接口，关闭深度思考；`ARK_VISION_MODEL` 可选，默认使用 `ARK_TEXT_MODEL`。
- 服务端按项目及小组校验图片归属和真实文件格式；缩小至1800像素并重新编码后提交。会话保存文件引用，不保存图片base64。
- 修复AI请求失败前清空输入文字的问题，文字及图片保留可重试；识别失败不扣额度，教师暂停及额度限制继续生效。

验证：76项回归通过；模拟摄像头浏览器验收覆盖拍摄、重拍、多张照片、选图、拒绝权限、延迟打开后关闭、原生相机回退、识别确认、请求失败重试及教师材料上传；既有课堂浏览器回归通过。

使用用户明确授权的新凭据识别程序生成的预算测试图片成功，耗时约3.2秒，准确返回预算100元、单价8元、数量10。凭据只用于测试进程，未写入文件或Git。

网页实时相机依赖HTTPS或localhost。物理手机/平板的权限弹窗、后置镜头选择和系统相机行为尚需真机验收；自动化使用合成视频源，没有访问实际摄像头。
