# DBR首轮课堂试用检查表

## 课前
- [ ] 学校网络、平板电量、浏览器和教师电脑完成测试。
- [ ] 每组一台横屏平板，桌面中央能够多人共同查看。
- [ ] 项目包、五阶段目标、阶段产出、提示额度和最高提示层级已配置。
- [ ] 教师审核知识材料和静态降级支架已经准备。
- [ ] 纸笔学习单/离线材料可在断网时继续使用。
- [ ] 研究版本号、教学模式版本、项目包版本和智能体版本已记录。

## 课中
- [ ] 学生理解“先思后助”和已有进展求助规则。
- [ ] 学生端没有因长文本聊天挤压小组面对面交流。
- [ ] L1-L3提示未直接输出完整模型、证明或最终结论。
- [ ] 多组共同卡点能够进入教师端聚合视图。
- [ ] 连续无效、复杂冲突和高阶数学判断能够转教师。
- [ ] AI暂停后共享工作区和阶段任务仍可继续。
- [ ] 未出现公开个人参与排名、能力标签或情绪标签。
- [ ] 教师能够从系统摘要回看原始证据。

## 课后
- [ ] 阶段提交、提示、版本和教师处理事件能够导出。
- [ ] 导出数据已去标识化，且不把求助次数解释为能力或情绪。
- [ ] 记录出现的技术故障、课堂中断和临时绕行策略。
- [ ] 记录哪些功能实际帮助课堂，哪些功能增加操作负担。
- [ ] 结合课堂观察、学生/教师访谈、项目成果和情绪量表进行DBR分析。
- [ ] 把修改建议映射回TR需求编号和MDR模式设计要求。
