# 腾讯云轻量应用服务器部署

本文对应广州地域的 4 核 4GB、40GB SSD、3Mbps 轻量应用服务器。约 14 台设备同时进行普通课堂操作足够；多人同时上传 PDF、照片或下载大文件时，3Mbps 是主要限制。AI 推理由火山方舟执行，不占本机推理算力。COS 存储桶也建议选择广州地域。

## 1. 购买与初始化

1. 选择 `Ubuntu Server 24.04 LTS 64bit`，22.04 LTS 也可。不要选择 Hermes Agent 等应用镜像。
2. 防火墙只放行 TCP `22`、`80`、`443`；SSH 的 22 端口最好仅允许教师或管理员的固定公网 IP。
3. 购买后设置 SSH 密钥或强密码，记录公网 IP。
4. 在域名 DNS 中添加 A 记录指向公网 IP。广州属于中国内地地域，对外正式提供网站前需要完成 ICP 备案。
5. COS 和 CDN 并非部署前置条件。先让源站 HTTPS 正常，再接 CDN，排错更简单。

## 2. 一键部署

SSH 登录服务器后执行：

```bash
sudo apt-get update
sudo apt-get install -y git
git clone https://github.com/Sean6869/math-project-collaboration-agent.git /opt/maple/app
sudo bash /opt/maple/app/deploy/tencent/deploy.sh
```

脚本会安装 Docker、构建应用、创建持久化数据卷，并用 Caddy 自动申请及续期 HTTPS 证书。按提示输入平台域名、管理员教师账号、管理员教师密码和火山方舟密钥。密钥写入权限为 `600` 的 `deploy/tencent/.env`，不会进入 Git。

查看状态与日志：

```bash
cd /opt/maple/app/deploy/tencent
sudo docker compose ps
sudo docker compose logs --tail=100 app
sudo docker compose logs --tail=100 caddy
curl -fsS https://你的域名/api/health
```

首次进入管理员端后，在“账号与访问管理”中创建教师、分配班级、设置小组数量和 `01`、`02` 等小组码。学生从管理员复制的班级入口进入，只选择小组并输入小组码。

## 3. 更新与回滚

代码推送到 GitHub 后，在服务器执行：

```bash
sudo bash /opt/maple/app/deploy/tencent/update.sh
```

更新只重建容器，不删除 `maple_data` 数据卷。更新前可在轻量服务器控制台创建备份点；需要代码回滚时，把仓库切到已验证提交后重新执行 `docker compose up -d --build`。不要执行 `docker compose down -v`，`-v` 会删除平台数据卷。

## 4. 清空课堂数据但保留管理员

先在轻量服务器控制台创建备份点，并确认 COS 备份成功。随后编辑：

```bash
sudo nano /opt/maple/app/deploy/tencent/.env
```

把 `MPT_RESET_DATA_ONCE=` 改为一个从未使用过的标记，例如 `MPT_RESET_DATA_ONCE=2026-10-26-first-clean`，然后运行更新脚本。平台启动时会先在持久化数据卷的 `/app/data/backups` 保存数据库和上传文件副本，再清空项目、过程记录、上传文件及其他教师账号，保留管理员身份。确认清空成功后将该变量恢复为空并再次执行更新脚本。同一标记不会重复清空。

## 5. COS 备份

平台当前需要在本机读取 PDF/图片并交给解析及 AI 链路，因此 COS 用于异地备份，不直接替代运行中的 `/app/data`。按腾讯云 COSCLI 文档安装工具，建议使用限定到备份桶目录的最小权限或临时密钥。配置后测试：

```bash
sudo MAPLE_COS_DESTINATION='cos://你的桶别名/maple/' \
  bash /opt/maple/app/deploy/tencent/backup-to-cos.sh
```

确认能在 COS 看到 `platform.db` 和 `uploads/` 后，可每天凌晨执行一次。使用 root 的 crontab：

```cron
20 2 * * * MAPLE_COS_DESTINATION=cos://你的桶别名/maple/ /opt/maple/app/deploy/tencent/backup-to-cos.sh >> /var/log/maple-cos-backup.log 2>&1
```

COS 建议开启版本控制，并设置生命周期：备份保留 30—90 天、旧版本和删除标记定期清理；同时设置容量告警。10GB 可作为初期备份空间，实际容量取决于教师上传的 PDF 和学生照片数量。

## 6. CDN 配置

先用独立子域名接入 CDN，例如 `class.example.com`，源站填轻量服务器公网 IP，回源 Host 填平台域名，回源协议选 HTTPS。缓存规则按优先级配置：

| 路径 | 策略 | 原因 |
|---|---:|---|
| `/api/*` | 不缓存 | 登录、课堂状态、上传下载均为动态或受权限保护 |
| `/*.html`、`/` | 不缓存 | 防止发布后仍显示旧页面 |
| `/assets/images/*` | 7 天 | 大图资源稳定，显著节省 3Mbps 回源带宽 |
| `/vendor/math-viz-kit/*` | 7 天 | 本地数学可视化静态文件 |
| `/assets/*.js`、`/assets/*.css` | 遵循源站 | 当前版本使用查询参数和 ETag，避免旧脚本造成前后端不一致 |

不要强制缓存带 `Set-Cookie` 或 `Cache-Control: private/no-store/no-cache` 的响应。发布新版本后如遇旧静态资源，执行 CDN 目录刷新 `/assets/`，不要刷新或预热 `/api/`。

## 7. 课堂前检查

```bash
cd /opt/maple/app/deploy/tencent
sudo docker compose ps
curl -fsS https://你的域名/api/health
sudo docker stats --no-stream
df -h
```

建议用 14 台设备做一次 10 分钟演练：同时登录、保存文字、上传 2—3 张照片、教师查看小组动态。若普通页面快而上传慢，先降低照片尺寸并检查 3Mbps 带宽是否跑满；CPU 和内存正常时，无需升级主机。若长期多人上传，优先升级带宽，其次才是服务器规格。
