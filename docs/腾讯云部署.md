# 腾讯云轻量应用服务器部署

本文适用于 Ubuntu 22.04/24.04 轻量应用服务器。当前部署使用 HTTP，访问 `http://公网IP:80/`。HTTP 不加密账号密码和课堂数据，浏览器拍照功能也可能不可用；正式使用建议配置域名和可信 HTTPS。

广州地域 4 核 4GB、40GB SSD、3Mbps 的配置足以支持约 14 台设备进行普通课堂操作。多人同时上传 PDF、照片或下载大文件时，公网带宽会成为主要限制；AI 推理由火山方舟执行，不占服务器本机推理算力。

## 1. 部署前准备

1. 使用 `Ubuntu Server 24.04 LTS 64bit`（22.04 LTS 也可），不要选择第三方应用镜像。
2. 腾讯云防火墙放行 IPv4 TCP `22`、`80`；不要把应用内部的 `8000` 端口暴露到公网。
3. 确保服务器可以出站访问 TCP `443`，用于拉取代码和镜像。
4. 准备管理员教师账号、至少 8 位的强密码，以及火山方舟 API Key。平台不需要 DeepSeek API Key。

## 2. 从零一键部署

SSH 登录全新服务器后执行下面一条命令，把示例 IP 换成服务器公网 IPv4：

```bash
curl -fsSL --retry 5 \
  https://raw.githubusercontent.com/Sean6869/math-project-collaboration-agent/main/deploy/tencent/first-deploy-ip.sh \
  | sudo bash -s -- 175.178.183.31
```

脚本会自动完成以下工作：

- 安装并启动 Docker 与 Docker Compose；
- 配置镜像加速并从 GitHub 克隆最新代码到 `/opt/maple/app`；
- 创建完整的 `deploy/tencent/.env`，不把密码或 API Key 写入 Git；
- 构建应用，创建持久化数据卷；
- 启动 HTTP 反向代理并验证健康接口。

如果无法使用远程脚本，可先克隆再运行：

```bash
sudo apt-get update
sudo apt-get install -y git curl
sudo git clone https://github.com/Sean6869/math-project-collaboration-agent.git /opt/maple/app
sudo bash /opt/maple/app/deploy/tencent/first-deploy-ip.sh 175.178.183.31
```

部署成功后直接打开：

```text
http://175.178.183.31:80/
```

脚本完成前不要关闭终端。如果无法访问，请检查服务器的 80 端口入站规则。

## 3. 后续更新

代码推送到 GitHub 后，在服务器执行：

```bash
sudo bash /opt/maple/app/deploy/tencent/update.sh
```

更新脚本会拉取 `main`、重建容器并保留 `maple_data` 数据卷。不要执行 `docker compose down -v`，`-v` 会删除平台数据。

## 4. 状态与排错

```bash
cd /opt/maple/app/deploy/tencent
sudo docker compose ps
sudo docker compose logs --tail=150 app
sudo docker compose logs --tail=150 caddy
curl -fsS http://127.0.0.1/api/health
```

正常结果中 `app` 应为 `healthy`，Caddy 应为 `Up`，健康接口返回包含 `"status":"ok"` 的 JSON。

配置文件位于 `/opt/maple/app/deploy/tencent/.env`。其中：

```dotenv
MAPLE_DOMAIN=175.178.183.31
MPT_ENV=production
MPT_COOKIE_SECURE=0
MPT_TEACHER_USERNAME=你的管理员账号
MPT_TEACHER_PASSWORD=你的管理员强密码
MPT_ACCOUNT_ENCRYPTION_KEY=脚本生成的随机密钥
ARK_API_KEY=你的火山方舟密钥
```

`MAPLE_DOMAIN` 只写纯公网 IPv4 或域名。`MPT_ACCOUNT_ENCRYPTION_KEY` 是 Fernet 密钥，已有数据时必须备份并保留原值，不能随意更换。不要把 `.env` 发给他人或提交到 GitHub。

## 5. 数据、备份与重装

平台数据位于 Docker 持久化卷 `maple_data`。重建应用容器不会清空它。执行系统重装前，先通过轻量服务器快照或仓库中的 COS 备份脚本备份：

```bash
sudo MAPLE_COS_DESTINATION='cos://你的桶别名/maple/' \
  bash /opt/maple/app/deploy/tencent/backup-to-cos.sh
```

COS 用于异地备份；平台仍需在本机读取 PDF、图片和数据库。没有域名时无需接入 CDN；14 台设备的课堂场景应先保证源站稳定，后续有域名并完成相应备案后再接 CDN。

重装系统后重新执行“从零一键部署”即可。新数据卷是空的；如需恢复旧数据，应先还原备份，再开放给用户使用。

## 6. 安全建议

- SSH 22 端口尽量只允许管理员固定公网 IP；
- 管理员密码至少 12 位并包含多种字符；
- API Key 只保存在权限为 `600` 的 `.env` 中；
- 定期执行更新脚本并创建服务器快照；
- 不开放 8000、2019 等容器内部端口。
