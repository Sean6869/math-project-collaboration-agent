# 运行架构与数据模型

浏览器只负责界面与同源 API 请求。`platform_server.py` 负责静态资源、会话、权限、SQLite、文件上传、研究导出与 DeepSeek 调用。

SQLite 主要表：

- `teachers`、`groups`、`sessions`：账户、访问码与会话；
- `states`：班级配置和各组工作区状态；
- `events`：阶段、保存、求助、教师处理和导出事件；
- `files`：教师审核材料元数据与可提取文本；
- `ai_calls`：模型标识、层级、耗时、状态和错误类别。

班级配置与小组状态分开保存。学生写入请求经过字段白名单，只能修改其会话对应小组；教师可以修改班级配置并查看指定小组。导出文件只使用组号，不包含学生姓名。

DeepSeek 调用链为：课堂规则 → 当前阶段与工作区 → 教师课程目标和知识材料 → 模型 → 长度与答案边界检查 → 返回提示或静态支架 → 记录事件。密钥不会返回浏览器。
